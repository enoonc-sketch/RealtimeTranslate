# 实时翻译 v2.9 — Windows 构建说明

当前环境是 Linux，**无法交叉编译出 Windows 程序**，请在 **Windows 电脑**上按下面步骤操作。

## 两个版本怎么选

| | 标准版 | 离线版（新） |
|---|---|---|
| 构建 | `build_exe.bat` | `build_offline.bat` |
| 形态 | 单个 exe（约 13 MB） | 文件夹（运行库 + 内置语言包，约 200~500 MB，取决于语言对数量） |
| 在线翻译（Google / 微软） | ✔ | ✔ |
| 离线翻译（断网可用，文字不出本机） | ✔ 在程序里点一下下载组件（约 35 MB） | ✔ 已内置 |
| 安装包 | `build_installer.bat` | `build_installer.bat offline` |

两个版本使用同一个程序名和安装 ID，**可以互相覆盖升级**，设置和开机自启通用。

## 构建标准版

1. 安装 [Python 3.9+](https://www.python.org/downloads/)，勾选 **Add python.exe to PATH**
2. 双击 `build_exe.bat` → 得到 `RealtimeTranslate.exe`

## 构建离线版（含离线安装包）

1. 安装 **64 位** [Python 3.9+](https://www.python.org/downloads/)（ctranslate2 没有 32 位版本）
2. （可选）编辑 `offline_models.txt`，选择要内置的语言对，默认中↔英。每对约 50~130 MB
3. 双击 `build_offline.bat`（**首次需要联网**，会下载 ctranslate2 和语言包）。它会依次：
   建独立虚拟环境 → 下载语言包到 `offline_models\` → 打包 → **自动自检**（真正加载模型翻译一句）
4. 得到 `dist\RealtimeTranslateOffline\`，里面的 `RealtimeTranslate.exe` 可直接运行，整个文件夹可复制给别人
5. 做成安装向导：安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)，运行 `build_installer.bat offline`
   → `Output\RealtimeTranslate_Offline_Setup_v2.9.0.exe`

**语言包下载不下来？**（`argos-net.com` 在部分网络下不通）
用浏览器 / 代理从 [索引](https://github.com/argosopentech/argospm-index)（`index.json` 的 `links` 字段）下载 `.argosmodel`，
放进 `offline_models\` 后重新运行 `build_offline.bat`，会自动识别；或用镜像：
`python prepare_offline_models.py --replace argos-net.com=镜像域名`。

**离线版运行时**：语言包在 `_internal\offline_models`（内置）和 `%APPDATA%\RealtimeTranslate\models`（用户导入）。
用户随时可在程序里点「离线语言包…」导入更多 `.argosmodel`，无需重新构建。

## v2.9 新增

### 悬停取词黑窗加固
- 2.6.0 给 OCR 调 PowerShell 时补了 CREATE_NO_WINDOW，但用户真机上仍报悬停取词闪黑窗。本轮三处起子进程的地方（OCR / 朗读 / 语音输入）在 CREATE_NO_WINDOW 之外再补 STARTUPINFO（STARTF_USESHOWWINDOW + SW_HIDE）双保险；悬停路径上其他位置（截图、托盘、网络检查、检查更新）全树核查过，都不 spawn 新进程。注意：如果装的还是 2.4.0（当时 _run_ps 根本没带这个标志），升级到 2.9.0 才能验证到底是哪一种原因。

### 代理设置（在线翻译引擎）
- 设置 → 离线与网络里加代理：启用开关、地址、端口、可选账号密码；配了就走代理，没配就和今天一样直连。只影响 Google / 微软在线翻译引擎；离线翻译、检查更新、语言包下载不走这个代理。密码只存本机 config.json，导出设置时不带出。

### 朗读语音选择
- 设置 → 翻译的朗读语速下面加「朗读语音」下拉框：列 Windows 已安装的语音（System.Speech 枚举），选了就记住，重启仍生效；选「系统默认语音」就是以前的行为。非 Windows 上只有默认语音一项。

### 翻译历史导出 .md
- 翻译历史的导出对话框里加 Markdown（按日期分组）：标题 + 导出时间/条数，每天一个二级标题，每条原文 + 译文 + 语言/引擎/来源（收藏带 ★）。原来的 CSV / TXT / JSON / Anki TSV 都还在。

## v2.8 新增

### 术语表 JSON 导入 / 导出
- 设置 → 翻译的术语表旁边加「导入…」「导出…」：JSON 文件，一份 `[{"src": ..., "dst": ...}]` 列表；导入会替换掉现在的术语表，导入完状态栏会说“导入 N 对，跳过 M 条重复/非法”；文件不对、JSON 坏了就弹错，什么都不改。

### 粘贴图片翻译（剪贴板图片 → 系统 OCR）
- 主窗口加「粘贴图片翻译」按钮，全局快捷键 Ctrl+Shift+V（设置 → 快捷键与关于里可改）：复制一张图片后按一下，程序读剪贴板里的图片（DIB 转 BMP，只用标准库），走系统 OCR 认字再翻译；剪贴板里没有图片时只在状态栏说一句，不弹窗、不崩。只在 Windows 上可用。

### 历史搜索
- 翻译历史窗口顶上的搜索框现在按原文或译文筛（整个输入当一个子串，大小写不敏感，中英文都行），和「只看收藏」「只看单词」可以一起用；旁边加 ✕ 按钮，一点就清空回到全部。

### 单实例
- 程序同时只能跑一份：Windows 用命名互斥体（和安装包的 AppMutex 同名），非 Windows 用临时目录下的锁文件；已经有一份在跑时，新启动的那份会把旧窗口提到前台然后自己退出。单实例检查本身出了任何问题都不会阻止启动（宁可多跑一份，也不让程序起不来）。

### 设置导出 / 导入
- 设置 → 常规里加「导出设置…」「导入设置…」：JSON 文件，含全部配置、术语表和自定义快捷键，不含任何密码。导入前先全量校验：JSON 坏了、顶层不是对象就整份拒绝；未知键、类型不对的值逐个忽略并在状态栏报数；数值超范围的按范围夹紧；绝不半应用。

### PDF 翻译（尽力而为）
- 「翻译文档…」现在也支持 .pdf：只用标准库（zlib 解 Flate 流、解析 Tj/TJ 文字操作、ToUnicode 能解析就用），按段落翻，输出是原文旁边的 `-译文.txt`（不写回 PDF）。注意：没有 ToUnicode 的内嵌字体可能出乱码，不保证版式与阅读顺序；提不出文字的 PDF（扫描件/图片型，少于 10 个字符）会直接告诉你改用截图翻译。

### 小打磨
- 翻译完状态栏末尾显示字数，例如“英文 → 中文 · Google · 原文 128 字 · 译文 96 字”。

## v2.7 新增

### 健壮性审计（先审代码，再修问题）
- 全树查了一遍所有 subprocess / 系统启动：OCR、朗读、语音输入三个调 PowerShell 的地方都带 CREATE_NO_WINDOW，不弹黑窗；macOS/Linux 的 `open`/`xdg-open` 只在非 Windows 上走，不涉及控制台窗口；`os.startfile` 与 `webbrowser.open` 不开控制台。
- 全树查了一遍后台线程：悬停取词、截图翻译、指针取词的 worker 之前在线程里直接读 Tk 下拉框/变量（`_codes()`、`smart_var.get()`、`winfo_screenwidth()`），Tk 控件不是线程安全的，改成在 Tk 线程里读好再传进 worker；文档/图片/语音 worker 本来就是这么做的，这次没动。
- 后台线程静默吞错：离线预热与网络检查的 worker 以前崩了就悄悄死掉（网络检查会一直卡在“检测中”），现在失败写进崩溃日志，网络检查还在界面上给出结论，不再卡住；悬停 OCR 失败仍静默退回双击取词（悬停本来就是静默的），但原因记在 `self._hover_ocr_err` 里方便查。

### 检查更新
- 设置 → 快捷键与关于里加「检查更新」按钮；启动后每天静默查一次（只在当天没查过时查），有新版才弹框问你要不要去下载页，绝不自动下载、绝不自动安装；断网、查不到时不弹窗，手动查才在状态栏说一句。

### .docx 文档翻译
- 「翻译文档…」现在也支持 .docx：只用标准库 zipfile + 字符串替换，段落译文写回第一个 `<w:t>`，其余字节（样式、图片、页眉页脚）原样保留，保存为 `-译文.docx`。

### 自定义术语表
- 设置 → 翻译里加术语表编辑框（每行 `原文 = 译文`，最多 200 对，每词 ≤40 字）：专有名词、产品名、品牌名按固定译文翻，不再被引擎翻走样；空着就是没有术语表，翻译和以前一样。实现是占位符保护（私有区字符，原文里撞上了会自动换一对）。

### 生词本导出 Anki
- 翻译历史导出多一种格式 .tsv：只导单词条目，每行「原文<TAB>译文」，UTF-8、无表头，Anki 里选制表符分隔直接导入。

### 深色外观（默认浅色，可选）
- 设置 → 常规里勾「深色外观」：主窗口、设置、历史、网络检查里的文本框与气泡/小窗口换成深色，对比度都过了 4.5:1；默认不勾，就是今天的浅色。以下几处故意不动：截图翻译的盖图层（画在截图上，颜色由截图决定）、托盘菜单（Windows 原生）、ttk 按钮与下拉框（Windows 原生主题下强行换肤会错位）。

### 悬停取词更快
- 指针静止时 2 秒内不再重复 OCR：同一范围、同一 8px 位置格的结果直接复用；指针移开、换范围、超过 2 秒就重新认。

### 小打磨
- 原文框里按 Ctrl+Enter 立即翻译，不用等 0.35 秒防抖；第一次运行（还没有配置文件）时状态栏会提示“在上方输入文字，或在任意软件里选中文字按 Ctrl+Alt+T 翻译”。

## v2.6 新增

### 文档翻译（.txt / .md / .srt）
- 主窗口「翻译文档…」按钮：选文件后在后台线程翻译，状态栏显示进度；翻完让用户选保存路径（默认在原文旁加 `-译文` 后缀），译文同时载入主窗口、存进历史（来源「文档翻译」）
- `.txt` / `.md` 按段落分块翻译，空行与段落结构原样保留；`.srt` 只翻字幕正文行，序号与时间轴逐字保留
- 实现是新模块 `doc_translate.py`（纯函数：`split_paragraphs` / `rebuild_paragraphs` / `srt_parse` / `srt_rebuild`，往返逐字还原有测试）；`.docx` 在 v2.7 加上了（标准库 zipfile），`.pdf` 在 v2.8 加上了（标准库提取正文，输出是 -译文.txt）

### 图片文件翻译
- 主窗口「翻译图片…」按钮：选 `.png` / `.jpg` / `.jpeg` / `.bmp` / `.tif` 文件，Windows 上复用已有的 `ocr_win.py` 系统 OCR 认字，认出的文字进主窗口翻译并存历史（来源「图片翻译」）
- 非 Windows 只在状态栏说「图片翻译只在 Windows 上可用」，不崩

### 词典释义 + 拼音/注音
- 只对 **Google 引擎**、输入是**单个词或短词组**（≤3 个词且 ≤20 字符）时，在译文下方新增一块「词典」区：词性 + 释义列表，以及响应里真有的 transliteration（中文显示「拼音：」，其他语言显示「读音：」）
- 解析是新函数 `parse_dict()`：从 `g_translate` 返回的原始 JSON 里读 `data[1]` 的词典与 `data[0]` 句子里的 transliteration 字段；**拼音绝不自己编**，响应里没有就不显示；解析不到整块隐藏，不报错、不显示空框

### 语音输入
- 主窗口「🎤 语音输入」按钮：只在 Windows 上有，点后在后台线程识别（新模块 `stt_win.py`，标准库 + PowerShell 5.1 的 System.Speech SpeechRecognitionEngine + DictationGrammar，识别到的文字经临时文件回传，绝不把语音内容拼进命令行；15 秒超时，超时即停），认到的文字填进原文框自动翻译
- 没麦克风 / 识别失败 / 超时都在状态栏明说；非 Windows 只报「语音输入只在 Windows 上可用」

### 生词本
- 主窗口历史按钮旁新增「生词本」按钮，直接打开只看单词的历史窗口；历史窗口里也加了「只看单词」复选框（原文是单个词、无空格、≤30 字符）
- 复用 `history_store`，不改表结构；单词判定是纯函数 `is_word_entry()`

### 界面字号
- 高级设置 → 常规 → 「界面字号」Spinbox 10~18，默认 11，改完立刻应用到原文 / 译文框、词典区与气泡 / 小窗口；配置键 `font_size`

### 翻译并替换原文（Replace as you go）
- 新增全局快捷键（默认 `Ctrl+Alt+R`，同样可在高级设置里自定义、重启生效）与托盘菜单项：记住当前前台窗口 → 复制选中文字 → 翻译 → 把译文写进剪贴板 → 切回原前台窗口 → 发送 Ctrl+V 粘贴替换
- 安全护栏：只在 Windows 上；粘贴前确认前台窗口还是刚才那个（句柄不一致就只把译文留在剪贴板并在状态栏说明）；终端窗口不做替换（避免 Ctrl+V / Ctrl+C 语义不同）；失败时译文仍在剪贴板，不丢结果

## v2.5 新增

### 朗读发音（Windows 自带语音，不装任何库）
- 主窗口新增「🔊 原文」「🔊 译文」按钮：点一下读，再点一次停；气泡 / 小窗口双击朗读译文（点一下还是复制），历史窗口「朗读译文」读选中记录的译文
- 实现是新模块 `tts_win.py`：只用 Windows 自带的 System.Speech（PowerShell 5.1 调起），文字写进 UTF-8 临时文件再读，**绝不把用户文字拼进命令行**；同时只读一个，再点就先停旧的；退出程序时自动停掉
- 高级设置 → 翻译 → 「朗读语速」-10（最慢）~ 10（最快），默认 0；配置键 `tts_rate`
- 需要本机装有对应语言的语音（设置 → 语言 → 添加语言），没有时会用默认语音读（可能读不准）或报朗读失败；非 Windows 上点朗读只在状态栏说「朗读只在 Windows 上可用」，不崩

### 复制闭环（把译文拿到别的软件里用）
- 主窗口新增「复制原文」按钮（复制后剪贴板监听不会把它当成新复制再翻一遍）；新增 `copy_bilingual()`：双语对照开着时按段逐行「原文 / 译文」，没开时是「原文全文 + 空行 + 译文全文」
- 高级设置 → 翻译 → 「翻译完成后自动复制译文到剪贴板」（配置键 `auto_copy`，**默认关**）：只对主窗口的翻译生效，成功后状态栏追加「· 已复制」；气泡 / 小窗口 / 悬停 / 截图的结果不自动复制

### 自定义全局快捷键（和别的软件冲突时终于有办法了）
- 高级设置 → 快捷键与关于：主窗口翻译 / 指针取词 / 截图翻译三个组合键都能改（下拉里有预设，也能自己打字），**保存后重启程序生效**（热键只在启动时注册一次，不在运行中途重注册）
- 组合格式：修饰键 Ctrl/Alt/Shift/Win（任意顺序）+ 一个键（字母 / 数字 / F1~F12），如 `Ctrl+Shift+T`；非法或重复的组合不保存，弹错并恢复成原来的值；坏配置启动时逐个回落到默认，程序照常能起
- 配置键 `hotkey_main` / `hotkey_pointer` / `hotkey_shot`（默认 `ctrl+alt+t` / `ctrl+alt+d` / `ctrl+alt+s`）；主窗口提示、设置页、托盘菜单、被占用提示显示的都是当前配置的快捷键，不再是写死的文字
- 旧配置文件照常可用（没有这三个键就用默认）；`parse_hotkey()` / `hotkey_label()` / `pynput_spec()` 是纯函数，可直接测试

## v2.4 新增

### 翻译历史（自动保存 / 收藏 / 搜索 / 导出 / 翻译记忆）
- 每次翻译成功都存下 原文、译文、语言、引擎、来源（主窗口 / 指针取词 / 悬停取词 / 截图翻译），
  只存在本机 `history.db`（SQLite，Python 标准库 `sqlite3`，不用装任何东西，也不上传）
- 主窗口「翻译历史…」打开历史窗口：搜索（空格分隔多个词都要出现）、只看收藏、
  双击或「载入到主窗口」把旧译文直接放回主窗口（不重新翻译）、复制译文、收藏、删除、
  导出（.csv 用 Excel 能直接打开中文 / .txt / .json）、清空（收藏的保留）
- 主窗口「☆ 收藏」收藏 / 取消收藏当前这条译文（没开历史时也会存下来）
- 相同（原文 + 源语言 + 目标语言）只存一条：再次翻译只更新译文 / 时间 / 次数，收藏不丢
- 高级设置 → 历史：自动保存开关、**翻译记忆**（相同原文直接用已存译文，不联网、断网也能用，默认关）、
  最多保存条数（默认 2000，超出删最旧的未收藏记录；收藏永远不会被自动删）
- 存储出问题（磁盘满、文件被占用、数据库损坏）不会影响翻译，只是不存
- 打包：两个 spec 里原先排除了 `sqlite3`，现已移出排除表并加入 hiddenimports（否则打包后历史功能会失效）

### 取词结果的显示方式 / 跟随指针的小窗口
高级设置 → 取词 → 「取词结果显示」（悬停取词和指针取词共用）：
- **气泡弹窗**（默认）：出现在指针旁，移开 / 点一下 / Esc 消失
- **跟随指针的小窗口**：固定大小、一直贴着指针走（15 秒后自动消失，下一次取词会替换它），
  不抢焦点、不挡鼠标；**宽 160~800、高 60~500 像素可调**，「预览」按钮即时看效果；
  文字太长时在固定大小内裁掉（完整译文仍进历史）；每次取词截屏前会先藏起来，不会被 OCR 认进去
- **不弹窗**：不显示任何弹窗，译文只写进主窗口（不弹出、不抢焦点）和历史

### 应用按钮 / 菜单上的字也能取
- 指针取词（Ctrl+Alt+D）：「I」形光标处仍是双击选词；复制不到东西（按钮、菜单、标签这类选不中的文字）
  就改用截屏 OCR 取指针处的单词——不点击，不会误触按钮
- 悬停取词：以前整个本程序窗口都不触发，现在只避开本程序的原文 / 译文文本框和弹窗，
  本程序自己的按钮、标签也能取
- 单词 / 整行的 OCR 截图会先平滑放大 2 倍再识别（小号界面字放大后才认得出），整段不放大

### 截图翻译：译文盖在截图上
- Ctrl+Alt+S 框选后，在原位置开一个无边框置顶窗：底图是截图，每一段原文上盖一块
  「取样的背景色 + 译文」（黑 / 白字按背景亮度自动选）；译文比原文长时盖块向下延伸
- 按段翻译（同一段的几行合在一起翻，上下文完整）；某一段失败只标红那一段，其余照常
- 左键点一下复制全部译文并关闭，右键 / Esc 关闭；同时把原文 / 译文同步到主窗口（不弹出）并存进历史
- 高级设置 → 取词 → 「截图翻译结果」可改回「显示在主窗口」（原来的行为）
- 实现全是标准库：GDI 截屏、`zlib` 编 PNG、Tk 8.6 原生读 PNG，不用 Pillow

### 点 × 不退出
点窗口右上角 × 永远不会把程序关掉：有托盘就隐藏到托盘；托盘建不起来（被安全软件拦截）
就最小化到任务栏（以前这种情况会直接退出）。真要退出：主窗口「退出」按钮、托盘菜单「退出」，
或在高级设置 → 常规 把「点窗口右上角 ×」改成「直接退出」。

### 托盘图标（Windows，纯 ctypes，不用 pystray / Pillow）
- 新模块 `tray_win32.py`：只用 Python 标准库 `ctypes` 调 `Shell_NotifyIconW`，
  图标直接读自带的 `app.ico`（`LoadImageW`，不用 Pillow 转格式），
  右键菜单用 `CreatePopupMenu` / `TrackPopupMenu`。
  装没装 pystray / Pillow 都不影响；两个 spec 都把 `pystray` 写进了排除列表。
- 点 × / 按 Esc：有托盘时隐藏到托盘（任务栏不留窗口），点托盘图标 / 双击找回；
  没托盘（比如被安全软件拦了）时退回旧行为：最小化。
  真正退出走托盘右键菜单「退出」或主界面「退出」按钮。
- 托盘右键菜单：显示主窗口 / 截图翻译 / 退出。托盘回调只往队列里放事件，
  真正的显示 / 退出由主线程处理，和全局热键的做法一样。
- 开机自启仍是 `--minimized` 启动，现在是最小化到托盘。

### 悬停取词（Windows，默认开）
- 选项里新增「悬停取词（鼠标停住自动取词）」，默认开，停住约 0.8 秒触发，
  可在配置里改 `hover_ms`（300~3000 毫秒）。
- 原理：先截光标周围一小块（单词 420×110、整行 900×90、整段 900×560），用系统 OCR 认出
  离光标最近的单词 / 整行 / 整段（由「范围」决定），
  不依赖软件本身是否支持选词——图片、游戏、扫描 PDF、按钮上的文字也能取。
  OCR 没认出、且光标是「I」形时，退回原来的双击取词；光标不是「I」形
  （按钮、链接）时绝不点击，不会误触发。
- 在主窗口里悬停不触发，避免自己取自己；气泡开着、正在取词、正在截图时也不触发。

### 截图翻译（Windows，Ctrl+Alt+S）
- 主界面新增「截图翻译」按钮，托盘右键菜单里也有；按 `Ctrl+Alt+S`
  （新注册的第三个全局热键，和 Ctrl+Alt+T / Ctrl+Alt+D 一样走系统热键）。
- 框选屏幕任意区域 → 截图 → 系统 OCR 认字 → 进主窗口翻译。
  截图用 `screen_win.py`（ctypes GDI `BitBlt` / `GetDIBits`，存 32 位 BMP，
  不用 Pillow）；OCR 用 `ocr_win.py` + `winocr.ps1` 调系统自带的
  `Windows.Media.Ocr`（Photos 应用用的同一个引擎，本地运行、不联网）。
- OCR 要求：Windows 10+，且装了对应语言的 OCR 语言包
  （设置 → 语言 → 添加语言；或 PowerShell 查 `Get-WindowsCapability -Online`
  里 `Language.OCR*`）。没装会在状态栏明说原因，不会静默失败。
  注意：OCR 走的是 Windows PowerShell 5.1（`powershell.exe`），
  PowerShell 7（`pwsh`）不支持 WinRT OCR，所以脚本里写死了 5.1 才能跑。

- 显示进度，可随时取消；下载内容必须是有效语言包，被网络拦截页替换会拒绝；装好后自动删除安装包、立刻可用
- 列表取不到时依次尝试 GitHub 和 jsDelivr 镜像；全都失败则显示上次保存的旧列表；对话框里的「镜像」栏（旧域名=新域名）用于下载链接本身不通时
- 语言包装到 `%APPDATA%\RealtimeTranslate\models`，与「导入」的位置相同，下载与手动导入可混用
- 仅离线版有此功能（标准版没有离线运行库）

### 标准版也能离线：程序内下载离线翻译组件（不用重新构建）
- 标准版点「离线语言包…」→ 询问「下载约 35 MB 组件」→ 同意后自动从 PyPI 官方下载 numpy / pyyaml / sentencepiece / ctranslate2 的预编译包，
  校验 SHA-256、安全解压到 `%APPDATA%\RealtimeTranslate\runtime`；**装好无需重启**，引擎里立刻出现「离线」，并自动进入语言包下载
- 之后每次启动自动加载这些组件；换了 Python 版本重新构建 exe 时会提示重新下载（轮子与 Python 版本绑定）
- 支持取消 / 断点续传 / 失败重试；「镜像」栏可填 `pypi.org=镜像域名;files.pythonhosted.org=镜像域名`（多组用分号）
- 组件占用磁盘约 100~200 MB；删除 `runtime` 文件夹即可卸载
- `realtime_translate.spec` 已把这些组件运行时要用的标准库显式打进标准版 exe（清单来自真实组件实测：`tests\real_runtime_check.py`）
- 需要 **64 位** 程序；若提示「无法加载」，安装「Microsoft Visual C++ 2015-2022 Redistributable (x64)」后重启

### 下载与启动的优化
- **断点续传**：下载中途取消 / 断网 / 关掉程序，已下载的部分会保留，再点下载接着下；传输中途断线会自动重试并续传。服务器不支持续传时自动从头下
- **速度与剩余时间**：下载进度行显示 MB/s 和预计剩余时间
- **打开更快**：语言包列表一天内直接用本地缓存，不用每次联网；「刷新列表」强制取最新
- **磁盘空间检查**：下载前按文件大小检查剩余空间，不够会直接提示还差多少 MB，而不是下到一半失败
- **离线引擎预热**：选「离线」引擎（或启动时已是离线）后，后台提前载入当前方向的模型，第一次翻译不再卡 1~3 秒
- **下载完成提示**：告诉你把引擎切到「离线」，或保持 Google（断网会自动改用离线）

### 指针取词（Ctrl+Alt+D）
- 把鼠标放在文字上按 **Ctrl+Alt+D**，在指针旁弹出小气泡显示译文；不打开主窗口、不抢焦点
- 气泡：点一下复制译文，右键 / Esc / 把指针移开就消失
- 选项「指针取词」可关闭；「范围」可选 **单词**（双击）、**整行**、**整段**；
  悬停取词和指针取词共用这个范围。整行 / 整段先走截图 OCR（不点击、图片里的字也行），
  OCR 取不到、且指针是「I」形时才退回三击（记事本、编辑器里选一行，浏览器、Word 里选一段）。
  整段是按「字高相近、行距正常、左右对齐」把相邻行合并，段间空行、标题、分栏会自动分开；
  段落超出截取范围（900×560）的部分取不到
- 原理：指针是「I」形文字光标时，才在指针处双击 / 三击选中文字，再复制翻译。
  **指针是箭头 / 手形（按钮、链接）时绝不点击**，所以不会误触发按钮或打开链接；
  终端窗口里没有选区时不会发送 Ctrl+C（避免中断正在运行的程序）
- 取词前会等 Ctrl / Alt 等键松开，避免变成 Ctrl+点击（比如在新标签页打开链接）
- `Ctrl+Alt+T`（取已选中的文字、结果在主窗口）保持不变
- 取词时会临时占用剪贴板并在取完后恢复；被取词的位置会留下选中高亮（这是双击的正常效果）
- macOS / Linux：不会自动点击，请先选中文字再按 Ctrl+Alt+D，译文同样显示在指针旁

## 其他说明

| 项目 | 说明 |
|---|---|
| DLL load failed | 安装「Microsoft Visual C++ 2015-2022 Redistributable (x64)」 |
| 杀毒误报 | PyInstaller 程序可能被误报；已关闭 UPX，可添加白名单或做代码签名 |
| 热键取词 | 会临时占用剪贴板，取词后恢复；剪贴板里若是图片/文件，恢复时会丢失 |
| 在线引擎 | Google / 微软均为非官方免费端点，可能随时变更或限流 |
| 离线质量 | Argos 模型体积小、速度快，但质量不及在线引擎；适合断网兜底和隐私场景 |
| 内存 | 每个已加载的翻译模型约 100~300 MB，最多同时驻留 3 个（超出自动卸载最久未用） |
