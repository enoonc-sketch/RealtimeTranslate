# 实时翻译 RealtimeTranslate

Windows 桌面翻译工具 v2.11：输入即译、全局热键取词、监听剪贴板、长文档翻译、在线 / 离线引擎。

## v2.11 新增

- **悬停整窗翻译**：设置 → 取词 →「悬停时翻译整个窗口（代替取词）」。鼠标在菜单 / 窗口上停住 ≥1.2 秒就整窗翻译，同一个窗口只翻一次，指针压在本程序自己的窗口上不触发。
- **文档翻译前预估耗时**：选完文件先估段数、字数和用时；段数 ≥2000 或预计 ≥1 分钟才会先问「现在开始吗」，小文档直接翻。翻译中状态栏显示「剩余约 N 分钟」。（取代了 v2.10 的「>5 MB 先问」。）
- **实时刷新**：主窗口勾选「实时刷新」并选间隔（2/3/5/10 秒），3 秒内把指针移到目标窗口，之后每隔几秒自动重新翻译这个窗口；译文层点击穿透，可以照常操作下面的软件；画面没变就不重复识别。取消勾选或再按整窗翻译热键停止。

## v2.10 新增 / 修复

- **整窗翻译（Windows，Ctrl+Alt+W）**：把指针放在下拉菜单、右键菜单、对话框或软件窗口上按热键，指针下的整个窗口一次截下来 → 系统 OCR → 整窗翻译，译文盖在原位（点一下复制全部，右键 / Esc 关闭）。热键不抢焦点，下拉菜单开着也能翻；菜单项、按钮这类短行逐行翻，成段正文按整段翻。主窗口的「整窗翻译」按钮和托盘菜单会先等 3 秒，让你把指针移到目标上。热键可在 设置 → 快捷键与关于 里改。
- **最小化到任务栏**：设置 → 常规 →「点窗口 ×」新增「最小化到任务栏」（窗口缩到任务栏，点任务栏图标还原；Esc 同样）；新增「点窗口 – 最小化」可选「留在任务栏」（默认）/「收进托盘」。
- **卸载时询问是否删除数据库**：卸载到最后会弹窗问「是否同时删除翻译历史数据库、设置、术语表、离线语言包」，默认按钮是「否」（保留）；静默卸载一律保留。以前卸载会无提示地把 `%APPDATA%\RealtimeTranslate` 整个删掉。
- **大文件卡死修复**：
  - 选完文件后读取、解析 .docx / .pdf 全部挪到后台线程（以前在界面线程里同步做，窗口「未响应」）；
  - 新增「取消翻译」按钮，翻译中随时可停；一段失败 / 取消后，排队的任务立刻退出（以前要等剩下每一段各自超时）；
  - 没有句号的大文件，合并断行不再退化成 O(n²)（6 万行实测 40 秒 → 0.03 秒），合并后一段最长 1500 字；超长单行切块同样改成线性；
  - 译文框最多显示前 15 万字，其余在内存里，「复制译文」和保存的文件仍是全文；
  - PDF：图片 / 字体流不再解压，单个流解压上限 32 MB（防压缩炸弹），内存不再随图片数暴涨；
  - 文件大小上限：txt / md / srt 50 MB、docx 100 MB、pdf 200 MB，超过直接提示；超过 5 MB 先问一句；
  - 进度消息节流、界面每轮最多处理 300 条消息，不会被消息队列淹没；
  - 顺带：GBK / UTF-16 编码的 txt、srt 现在也能打开（以前只认 UTF-8）。

## v2.9 新增

- **安装版本**：提供安装向导（Inno Setup），开始菜单、卸载项齐全，标准版与离线版共用 AppId、互相覆盖升级。
- **悬停取词黑窗加固**：OCR、朗读、语音识别三处子进程调用都加了 CREATE_NO_WINDOW + STARTUPINFO 双保险，悬停不再弹黑控制台窗口。
- **代理设置**：设置 → 离线与网络，可配 HTTP/HTTPS 代理（地址、端口、账号密码），在线翻译走代理；不配时和原来一样。
- **朗读语音选择**：设置 → 翻译，可选 Windows 已安装的朗读语音。
- **历史导出 .md**：历史记录可导出 Markdown（按日期分组、原文 + 译文）。

## v2.4 新功能

- **托盘图标（Windows）**：只用 Python 标准库 `ctypes` 调 `Shell_NotifyIconW`，不依赖 pystray / Pillow。点 × / Esc 藏到托盘，右键菜单：显示主窗口 / 截图翻译 / 退出。
- **悬停取词（Windows，默认开）**：鼠标在文字上停住约 0.8 秒自动取词。先截光标周围一小块，用系统 OCR 定位最近的单词，图片、游戏、扫描 PDF 里也能取；认不到且光标是「I」形时退回双击取词。
- **截图翻译（Windows，Ctrl+Alt+S）**：框选屏幕任意区域 → 系统 OCR 认字 → 翻译。截图用 GDI `BitBlt`，OCR 用系统自带的 `Windows.Media.Ocr`，全程不装第三方库。需要安装对应语言的 OCR 语言包。

## 构建（Windows）

```bat
build_exe.bat        :: 标准版：单个 exe，约 13 MB
build_offline.bat    :: 离线版：内置 ctranslate2 + 离线语言包
build_installer.bat  :: 安装向导（需 Inno Setup 6）
```

需要 Python 3.9+（离线版要 64 位）。详细说明见 [README_BUILD.md](README_BUILD.md)。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+Alt+T | 翻译选中的文字 |
| Ctrl+Alt+D | 指针取词，在指针旁显示译文 |
| Ctrl+Alt+S | 截图翻译 |
| Ctrl+Alt+W | 整窗翻译（指针下的整个菜单 / 窗口） |

## 文件

- `desktop_translator.py` — 主程序
- `tray_win32.py` — Windows 托盘（纯 ctypes）
- `screen_win.py` — Windows 截图（ctypes GDI）+ 取指针下的窗口范围
- `ocr_win.py` + `winocr.ps1` — Windows 自带 OCR
- `offline_engine.py` — 离线引擎（Argos 语言包 + ctranslate2）
- `tests/` — 测试
